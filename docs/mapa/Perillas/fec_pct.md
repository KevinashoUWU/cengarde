# `fec_pct`

FEC v3: las reparaciones, % de los bytes de DATA, haya o no pérdida. Un enlace de parte s detenido T se rehace unos s·T / (r·(1 − s)) después de empezar: con cuatro enlaces, 50 ms piden ~25 %.

- **Sección:** global
- **Extremo:** cliente
- **Por omisión:** 10
- **Rango:** 1–50
- **Pieza:** [[FEC v3 (fec3.h)]]
- **Historia:** [[026-fec-v3]]
