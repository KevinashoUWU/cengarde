# `reorder_active`

Un hueco espera solo a los enlaces por los que el otro extremo llevó datos hace poco (la máscara de sus sondas, C2); `no`: a todos los no silenciados, como antes.

- **Sección:** global
- **Extremo:** los dos
- **Por omisión:** `yes`
- **Rango:** `yes` o `no`
- **Pieza:** [[Reordenador (reorder.h)]], [[Enlaces activos (active.h)]]
- **Historia:** [[013-capacidad-y-dosificacion]]
