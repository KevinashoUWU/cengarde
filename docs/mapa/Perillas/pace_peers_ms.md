# `pace_peers_ms`

La ventana de las copias hacia los demás enlaces de una sesión con Starlink, sobre los 60 ms del preset; el cliente para la subida, el servidor para la bajada.

- **Sección:** global
- **Extremo:** los dos
- **Por omisión:** -1 (el del preset: 60 ms en `starlink`)
- **Rango:** 0–2000 (0: apagado)
- **Pieza:** [[Copias a tiempo (eta.h)]], [[Modelo de enlace (linkmodel.h)]]
- **Historia:** [[015-modelo-de-enlace]], [[017-terreno-nostalgica]]
